# Neousys Ops Toolkit (Planning + Warehouse Automation)

This is a collection of internal tools I built at Neousys Technology to reduce manual work, improve planning accuracy, and standardize warehouse execution.

## 1) Planning (Inventory + Production)

- [**ERP_System**](https://github.com/playoung2818/ERP_System) — Supply-side scheduler from Sales Order intake to production readiness
- [**Labor/Work Hours Calculator**](https://github.com/playoung2818/Working-Hour-Calcultor) — Converts WO workload into labor-hour capacity planning

## 2) Receiving

- [**Receiving Process**](https://github.com/playoung2818/Receiving_Automate) — Receiving log + validation tooling to reduce input errors and improve traceability

## 3) Picking & Kitting

- [**Part Name Lookup**](https://github.com/playoung2818/Lookup-Part-Name-by-Serial-Number) — Lookup part name by serial number with pruning utilities
- [**WO_Content_Checker**](https://github.com/playoung2818/Word-Content-Check) — Validates work order content / completeness to prevent pick errors
- [**Serial-Number-Prune](https://github.com/playoung2818/Serial-Number-Prune)** —  Prune and Sort scanned serial number

## 4) Document Management

- [**Quickbooks_WO_Viewer**](https://github.com/playoung2818/Quickbooks-work-order-viewer) — System integrate pdfs, docs.
- [**File Watcher**](https://github.com/playoung2818/File_Watcher) — Monitors folders and logs PDF/Word changes into database
- [**File Rename**](https://github.com/playoung2818/File_Rename) — Standardizes filenames to enforce data hygiene and searchability
- [**POD Update Print**](https://github.com/playoung2818/POD_Update-Print) — Walk through one drive Folder, update to excel, print PDF
