# Neousys Ops Toolkit (Planning + Warehouse Automation)

This is a collection of internal tools I built at Neousys Technology to reduce manual work, improve planning accuracy, and standardize warehouse execution.

## 1) Planning (Inventory + Production)
- **ERP_System** — Supply-side scheduler from Sales Order intake to production readiness
- **Labor/Work Hours Calculator** — Converts WO workload into labor-hour capacity planning

## 2) Receiving
- **Receiving Process** — Receiving log + validation tooling to reduce input errors and improve traceability

## 3) Picking & Kitting
- **Part Name Lookup** — Lookup part name by serial number with pruning utilities
- **WO_Content_Checker** — Validates work order content / completeness to prevent pick errors

## 4) Document Management
- **File Watcher** — Monitors folders and logs PDF/Word changes into database
- **File Rename** — Standardizes filenames to enforce data hygiene and searchability
