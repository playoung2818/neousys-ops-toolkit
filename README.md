# Neousys Ops Toolkit (Planning & Warehouse Automation)

A collection of internal tools I designed and built at Neousys Technology to automate routine operations, reduce manual effort, and improve execution consistency across planning and warehouse workflows.

## 1) Planning (Inventory & Production)

- [**ERP_System**](https://github.com/playoung2818/ERP_System) — Planning system for inventory availability and production readiness  
- [**Labor / Work Hours Calculator**](https://github.com/playoung2818/Working-Hour-Calcultor) — Calculates expected labor hours for work orders  

## 2) Receiving

- [**Receiving Process**](https://github.com/playoung2818/Receiving_Automate) — Automates receiving workflows to reduce manual input and processing errors  

## 3) Picking & Kitting

- [**Part Name Lookup**](https://github.com/playoung2818/Lookup-Part-Name-by-Serial-Number) — Serial-number–based part identification with pruning utilities  
- [**WO Content Checker**](https://github.com/playoung2818/Word-Content-Check) — Validates Work Order Output Form content against work orders to prevent picking errors  
- [**Serial Number Prune**](https://github.com/playoung2818/Serial-Number-Prune) — Cleans, deduplicates, and sorts scanned serial numbers  

## 4) Document Management

- [**QuickBooks WO Viewer**](https://github.com/playoung2818/Quickbooks-work-order-viewer) — Centralized viewing and linking of work-order PDFs and documents  
- [**File Watcher**](https://github.com/playoung2818/File_Watcher) — Monitors folders and logs PDF and Word file changes into a database  
- [**File Rename**](https://github.com/playoung2818/File_Rename) — Standardizes filenames to improve data hygiene and searchability  
- [**POD Update & Print**](https://github.com/playoung2818/POD_Update-Print) — Traverses OneDrive folders to update Excel records and generate printable PDFs
